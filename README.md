# Student Management System

A console-based **Student Management System** developed using Java. The application allows users to manage student records through a simple menu-driven interface.

## Features

* Add student records
* View all students
* Search students by ID
* Update student information
* Delete student records
* Prevent duplicate student IDs
* Validate user input
* Validate age and marks
* Delete confirmation
* Calculate student statistics
* Automatically assign grades
* Sort students by ID or name

## Technologies Used

* Java
* Object-Oriented Programming
* ArrayList
* Exception Handling
* Collections and Comparator
* Scanner

## How to Run

### 1. Compile the Application

```bash
javac Student.java StudentManagementSystem.java
```

### 2. Run the Application

```bash
java StudentManagementSystem
```
